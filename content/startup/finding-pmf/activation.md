**Activation** is when a new user first experiences the product's core value — not signup, not login, but the moment it *works for them*: first report generated, first order received, first automated workflow live. The activation rate (signups reaching it) is the highest-leverage number in early growth, because everything downstream multiplies it.

```text
100 signups → 40 activate (40%) → 15 retain → 3 pay
doubling activation doubles everything downstream — cheapest growth available
```

Find your activation event empirically: correlate early actions with long-term retention, and the actions that predict staying define activation (not opinions about what should matter). Then engineer the new-user path to deliver it fast — every step, field and wait between signup and value is conversion tax.

The classic mistakes:

- Defining activation as signup. Celebrating registrations while value delivery languishes measures marketing, not product. Activation must be value received, strictly defined.
- Onboarding tours instead of value fast. Seven-step product tours delay the moment; checklist onboarding that front-loads setup work. Ruthlessly shorten time-to-value: templates, defaults, imports, concierge help.
- One activation for all segments. Different users activate on different value. Segment the definition (and the onboarding) or optimize for nobody in particular.
- Ignoring the setup chasm. The gap between signup and value — integrations, invites, data import — is where most users die. Instrument each step ([funnel](/t/funnel-analysis)) and attack the biggest drop first.
- Activation theater. Auto-playing demos and fake "success" states inflate the metric while users learn nothing. Real value received, measurably, or the number lies.

**Own it jointly:** product builds the path, marketing sets expectations that match it, success intervenes with stragglers. Activation is the whole company's first impression, quantified.
